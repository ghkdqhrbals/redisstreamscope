Redis Streams monitoring UI

Redis Streams needed a proper monitoring UI.

We could not find a monitoring UI made specifically for Redis Streams, so we built StreamScope. Start it with one Docker command, then connect Redis in the browser.

Run with Docker View source
Quick start 
docker run -d \
  --name streamscope \
  -p 8080:8080 \
  -v streamscope-data:/data \
  ghcr.io/ghkdqhrbals/streamscope:latest
Open localhost:8080
Sign in admin / password

Quick start

Start first. Configure inside.

1

Start StreamScope

docker run -d --name streamscope -p 8080:8080 -v streamscope-data:/data ghcr.io/ghkdqhrbals/streamscope:latest
2

Sign in

http://localhost:8080 · admin / password

3

Connect Redis

Open Settings → Redis connections. Add your server, test it, and save. Standalone, Sentinel, Cluster, ACL, passwords, and TLS are all supported.

Docker Desktop host Redis Use host.docker.internal:6379 instead of localhost:6379 on macOS and Windows.
